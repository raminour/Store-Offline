## 🇪🇬 بالعربية (Arabic)

أداة قوية لتنزيل برامج وتطبيقات Microsoft Store بشكل أوفلاين، لتعمل على أي جهاز ويندوز بدون الحاجة إلى اتصال بالإنترنت.

### ✨ المميزات
*   **تنزيل أوفلاين:** نزّل البرامج مرة واحدة واستخدمها على أي جهاز بدون نت.
*   **دعم MSIX و AppX و Win32:** يتعامل مع جميع أنواع الحزم من المتجر.
*   **واجهة رسومية (GUI):** سهلة الاستخدام مع دعم اللغة العربية والإنجليزية.
*   **واجهة كونسول (CLI):** للمستخدمين المتقدمين وأوامر الأتمتة.
*   **تعدد التبويبات:** نزّل أكثر من برنامج في نفس الوقت (عبر طابور).
*   **كيت أوفلاين (Offline Kit):** أنشئ مثبتاً يعمل بدون إنترنت لأي جهاز آخر.
*   **توافق واسع:** يعمل على ويندوز 7 و 8 و 10 و 11 مع PowerShell 3.0 أو أحدث.

### 🚀 طريقة الاستخدام
1. قم بتحميل ملف `Store-Offline.cmd` من قسم [Releases](https://github.com/raminour/Store-Offline/releases/latest).
2. دوس دبل كليك على الملف عشان تفتح الواجهة الرسومية.
3. اكتب اسم البرنامج أو الصق رابط المتجر أو رقم المنتج.
4. اضغط **Search**، اختار البرنامج، واضغط **Download**.

### 🛠️ المتطلبات
*   نظام التشغيل: Windows Vista أو أحدث (للتنزيل).
*   PowerShell 3.0 أو أحدث.
*   للتثبيت: Windows 8 (AppX) أو Windows 10 1809 (MSIX).

## 🇬🇧 In English

A powerful tool to download Microsoft Store apps offline, designed to work on any Windows device without an internet connection.

### ✨ Features
*   **Offline Download:** Download apps once and use them on any device without internet.
*   **Supports MSIX, AppX, and Win32:** Handles all package types from the Store.
*   **Graphical User Interface (GUI):** Easy to use with Arabic and English support.
*   **Command Line Interface (CLI):** For advanced users and automation scripts.
*   **Multi-Tab Support:** Queue and download multiple apps simultaneously.
*   **Offline Kit:** Create an offline installer for any other device.
*   **Wide Compatibility:** Works on Windows 7, 8, 10, and 11 with PowerShell 3.0+.

### 🚀 Usage
1. Download `Store-Offline.cmd` from the [Releases](https://github.com/raminour/Store-Offline/releases/latest) section.
2. Double-click the file to open the GUI.
3. Enter the app name, paste a Store link, or enter a Product ID.
4. Click **Search**, select the app, and click **Download**.

### 🛠️ Requirements
*   OS: Windows Vista or newer (for downloading).
*   PowerShell 3.0 or newer.
*   For installation: Windows 8 (AppX) or Windows 10 1809 (MSIX).
